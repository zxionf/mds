## 3 语法特性

### 3.1 Shadowing

使用同名变量覆盖，新的变量会隐藏之前声明的同名变量  
类型可以不同

### 3.2 数据类型

#### 3.2.1 标量类型：布尔、整数、浮点数、字符  

- i8 i16 i32 i64 i128 isize u8 u16 u32 u64 u128 usize  
9876 0xff 0o77 0b11 b'A' 前面几种均可使用下划线,同样可以用类型后缀 如 67u32  
- f64是默认的浮点类型  
- char 描述语言中最基础的单个字符 **占4字节** 是 unicode标量值

#### 3.2.2 聚合类型：元组、数组、切片  

- 元组

```rust
let tup: (i32, f64, u8) = (500, 6.4, 1);
// 使用模式匹配解构
let (x, y, z) = tup;
// 或者使用点标记索引
tup.0
```

- 数组

```rust
let a = [1, 2, 3, 4, 5];
let a: [i32; 5] = [1, 2, 3, 4, 5];
let a: [3; 5]; //相当于 [3, 3, 3, 3, 3]
```

- 切片

```rust
let slice = &a[1..3];
```

### 3.3 所有权

所有权是Rust的基本概念，它决定变量在程序中的生命周期。  

- 每个值都有一个变量，这个变量是该值的所有者
- 每个值同时只能有一个所有者
- 当所有者离开作用域时，该值将被删除

```rust
let s1 = String::from("hello");
let s2 = s1;
// s1无效
// 发生移动
```

### 3.4 引用与借用

引用是Rust的基本概念，它允许我们创建一个指向其他变量的指针  
把引用作为函数参数的行为叫借用  

在特定的作用域中，对于一块数据，只能有一个可变引用  
不可以同时拥有一个可变引用和一个不可变引用

三种行为会发生数据竞争:

- 两个或者多个指针同时访问同一个数据
- 至少有一个指针用于写入数据
- 没有使用任何机制来同步对数据的访问

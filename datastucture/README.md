# 数据结构

## 1 线性表

### 1.1 要点

至多有一个前驱至多有一个后继

### 1.2 形式

顺序表，单链表，双向链表，循环链表

## 2 栈和队列

### 2.1 栈

后进先出，即LIFO  
可定义为只允许在表的末端进行插入和删除的线性表。

### 2.2 队列

先进先出，即FILO  
只允许在表的一端插入，在另一端删除。

## 3 树

### 3.1 二叉树

`完美二叉树` 所有叶子节点在同一层且所有中间节点度均为2的二叉树  
`满二叉树` 所有节点的度均为0或者2的二叉树  
`完全二叉树` 除最深的那一层外，其他层节点全部填满，最深层的节点尽量向左填满的二叉树  

#### 3.1.1 堆

堆是一种带节点约束的完全二叉树  
`小根堆` 所有节点的值都不大于其左右孩子  
`大根堆` 所有节点的值都不小于其左右孩子
